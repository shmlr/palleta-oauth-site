Palleta Gmail Automation

Внутренняя интеграция магазина «Паллета» для получения отчётов 1С из Gmail и подготовки проверенных обновлений справочных клубных цен для приложения «Меню на неделю».

Что делает приложение

  1. Получает согласие владельца Gmail на доступ только для чтения.
  2. Ищет письма с утверждёнными отправителем и темой и временно загружает вложения XLS.
  3. Проверяет структуру, дату, коды и перечень заранее согласованных товаров.
  4. Создаёт предложение изменения цен в GitHub для проверки перед публикацией.
Разрешение Gmail API технически даёт возможность читать весь ящик, хотя автоматизированная обработка настроена на конкретные отчёты. Приложение не отправляет и не удаляет письма.

Обработка данных

Сырые вложения, закупочные цены и остатки не предназначены для публикации. Подробнее: политика конфиденциальности.
