Политика конфиденциальности

Эта политика относится к служебной интеграции Palleta Gmail Automation, используемой для проверки отчётов 1С из электронной почты.

Оператор и контакты

Для запросов об обработке или удалении данных: shmlrd01@gmail.com. Интеграция предназначена для внутреннего использования владельцем ящика.

Какие данные обрабатываются

После явного согласия приложение использует область доступа https://www.googleapis.com/auth/gmail.readonly. Она технически позволяет читать письма и вложения. Программа ищет сообщения с определёнными отправителем и темой, проверяет время получения и обрабатывает XLS с номенклатурой, кодами, клубными ценами и другими полями, необходимыми для проверки отчёта.

Цели обработки

Проверка подлинности и структуры отчётов, сопоставление заранее подтверждённых товаров и подготовка предложений обновления клубных справочных цен. Данные не используются для рекламы, продажи персональных сведений или обучения собственных моделей ИИ.

Хранение и защита

Вложения XLS обрабатываются во временной среде GitHub Actions и удаляются после завершения задачи. Сырые письма, исходные файлы, остатки и закупочные цены не публикуются в GitHub Pages и не должны помещаться в публичный репозиторий, логи или артефакты. В открытом каталоге могут появляться только проверенные справочные клубные цены и даты. OAuth-токены хранятся как GitHub Actions Secrets. Google и GitHub имеют собственные правила технического хранения данных.

Передача третьим лицам

Для работы используются Gmail API (Google) и GitHub Actions (GitHub) согласно их условиям. Интеграция не передаёт данные рекламодателям.

Отзыв доступа и удаление

Разрешение можно отозвать на странице подключённых приложений Google. После отзыва автоматическое чтение новых писем прекращается. Для запросов об удалении сохранённых результатов пишите по указанному контактному адресу.

Изменения

Политика может пересматриваться при изменениях интеграции или применимых требований. Актуальная версия доступна на этой странице.
